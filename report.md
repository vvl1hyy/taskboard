1. **Яка адреса сторінки в браузері? З яких частин вона складається?**
Адреса виглядає як `http://127.0.0.1:5500/index.html`. Вона складається з протоколу (http), адреси хоста (127.0.0.1 — твій комп'ютер або localhost), номера порту (5500 — «двері» сервера) та шляху до файлу (/index.html).

2. **Скільки запитів зробив браузер при завантаженні сторінки і чому саме стільки?**
Браузер зробив 2 запити: перший — за самим файлом `index.html`, другий — за зображенням `logo.jpg`, оскільки воно підключене всередині HTML-коду через тег `<img>`.

3. **Что відбулось, коли ти поставив неправильний шлях до зображення?**
Зображення не завантажилося, на його місці з'явився стандартний значок битої картинки (або пусте місце), а браузер у вкладці Network видав помилку зі статусом `404 Not Found`.

4. **Чому зміни, зроблені через DevTools, зникли після F5?**
DevTools змінює лише поточний стан сторінки в оперативній пам'яті браузера (DOM-дерево в реальному часі). Сам файл `index.html` на диску не змінюється, тому після оновлення сторінки (F5) браузер знову завантажує оригінальний файл із файлової системи.

5. **Хто в цій схемі клієнт, а хто сервер?**
Браузер (Google Chrome, Edge тощо) виступає в ролі клієнта, який надсилає запити. Live Server у VS Code виступає в ролі локального сервера, який приймає ці запити та віддає назад файли сайту.
